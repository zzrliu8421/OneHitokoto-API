接口文档

API 说明

动漫也好、小说也好、网络也好，不论在哪里，我们总会看到有那么一两个句子能穿透你的心。

请求地址

GEThttps://hitokoto.api.sylv.top/api
提示：本服务支持 EdgeOne Pages 和阿里云 ESA 多平台部署，数据来源于 hitokoto-osc/sentences-bundle。

请求参数

参数值可选说明
c见分类表是句子类型
encodejson / text / js是返回编码，默认 json
charsetutf-8是字符集，默认 utf-8
callback如：moe是JSONP 异步回调函数
select默认：.hitokoto是选择器，配合 encode=js 使用
min_length默认：0是返回句子的最小长度（包含）
max_length默认：30是返回句子的最大长度（包含）

示例请求

GET/api?c=f
GET/api?encode=text
GET/api?callback=myCallback
GET/api?min_length=10&max_length=50

返回值说明

返回参数描述
id一言标识
uuid一言唯一标识
hitokoto一言正文
type类型
from一言的出处
from_who一言的作者
creator添加者
creator_uid添加者用户标识
length句子长度

响应示例

{

  "uuid": "75a45fd4-4f2f-45eb-80cb-6f0a7bcdfaf2",

}

使用流程

三步即可接入

无需复杂配置，几分钟即可在你的项目中集成一言服务。

01

调用接口

向 /api 发送 GET 请求，即可获取随机一言的 JSON 数据。

02

选择参数

按需添加分类、编码格式、长度过滤等参数，精准获取所需句子内容。

03

展示内容

在前端页面渲染返回的句子，支持纯文本、JSON、JS、JSONP 多种格式。

常见问题

FAQ

关于一言 API 服务的常见问题解答。

数据来源于 hitokoto-osc/sentences-bundle 开源项目，通过 GitHub Actions 每天自动从远程源获取最新数据。
支持 EdgeOne Pages（腾讯云）和阿里云 ESA 两个平台部署。两个分支的 API 功能完全一致，仅部署平台和配置文件不同。
使用 ?c=分类码 参数指定分类，例如 ?c=a 获取动画类。支持多分类组合，如 ?c=a&c=c。
完全支持。服务已开启全 CORS 支持，前端可直接调用，也支持 JSONP 回调方式跨域获取。
添加 ?encode=text 参数即可返回纯文本格式，此外还支持 json（默认）和 js 格式。
