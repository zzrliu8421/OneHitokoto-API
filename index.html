API Reference

接口说明

“不论在哪里，总有那么一两个句子能穿透你的心。”

请求地址

GET https://hitokoto.api.sylv.top/api
支持 EdgeOne Pages 与阿里云 ESA 多平台部署。数据来自 hitokoto-osc/sentences-bundle。

请求参数

参数取值必填说明
c见分类表否句子类型，可多选 ?c=a&c=c
encodejson / text / js否返回编码，默认 json
charsetutf-8否字符集，默认 utf-8
callback如：moe否JSONP 回调函数
select默认 .hitokoto否配合 encode=js 的选择器
min_length默认 0否最小长度（包含）
max_length默认 30否最大长度（包含）

示例请求

GET /api?c=f
GET /api?encode=text
GET /api?callback=myCallback
GET /api?min_length=10&max_length=50

返回值

字段说明
id一言标识
uuid唯一标识
hitokoto正文
type类型代码
from出处
from_who作者
creator添加者
creator_uid添加者 ID
length句子长度
