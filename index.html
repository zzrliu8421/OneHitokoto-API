支持 EdgeOne Pages 与阿里云 ESA 多平台部署。数据来自 hitokoto-osc/sentences-bundle，每日自动同步。

请求参数

参数取值必填说明
c见签台签牌否句子类型，可多选 ?c=a&c=c
encodejson / text / js否返回编码，默认 json
charsetutf-8否字符集，默认 utf-8
callback如：moe否JSONP 回调函数
select默认 .hitokoto否配合 encode=js 的选择器
min_length默认 0否最小长度（包含）
max_length默认 30否最大长度（包含）

返回值

字段说明
id一言标识
uuid唯一标识
hitokoto正文
type类型代码
from出处
from_who作者
creator添加者
length句子长度
category_name分类名称

更多用法

GET /api?c=f — 只要网络类句子
GET /api?encode=text — 返回纯文本
GET /api?callback=myCallback — JSONP 跨域回调
GET /api?min_length=10&max_length=50 — 按长度过滤
GET /api/categories — 获取分类列表

问签

数据来自 hitokoto-osc/sentences-bundle 开源项目，通过 GitHub Actions 每日自动同步最新句子。
支持 EdgeOne Pages（腾讯云）与阿里云 ESA。二者 API 完全一致，仅部署配置与构建产物不同。
使用 ?c=分类码，如 ?c=a 获取动画类；多分类可组合 ?c=a&c=c。签台上的十二支签牌即对应十二个分类码。
完全支持。已开启全量 CORS，浏览器可直调；亦提供 JSONP 回调方式。
附加 ?encode=text 即返回纯文本；默认 json，另支持 js。
